# SQLD 합격 대시보드

SQLD(SQL 개발자) 시험 준비를 위한 학습 웹앱입니다. 이론 학습, 예상문제, OX퀴즈, 실전 모의고사를 한 페이지에서 제공합니다.

## 실행 방법

별도의 빌드 과정이 없는 순수 HTML/CSS/JS 단일 파일입니다.

- 가장 간단하게는 `index.html`을 브라우저로 더블클릭해서 열면 됩니다.
- 로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Source**를 `Deploy from a branch` → `main` / `(root)`로 설정하면
`https://baekks.github.io/sqld_study/`로 바로 접속할 수 있습니다.

## 파일 구조

```
index.html   실제 서비스 파일 (CSS·JS·데이터가 전부 이 한 파일 안에 있음)
README.md    이 문서
```

빌드 도구나 외부 라이브러리 의존성이 전혀 없습니다. `index.html`만 수정하고 저장하면 바로 반영됩니다.

## 코드 구조

`index.html` 안에서 대략 이런 순서로 구성되어 있습니다 (괄호 안은 대략적인 줄 번호, `git log` 이후 조금씩 바뀔 수 있어요).

| 영역 | 위치 | 설명 |
| --- | --- | --- |
| CSS 디자인 토큰 | 파일 상단 `<style>` | `--bg`, `--accent` 등 CSS 변수로 라이트/다크 테마 색상을 정의 |
| 문제 카테고리 정의 | `var CATS` (~528줄) | 1-1/1-2/2-1/2-2/2-3 다섯 파트의 id·label |
| 손으로 작성한 예상문제 | `var QUESTIONS` (~538줄) | 초기에 직접 작성한 시나리오형 문제 30개 |
| 용어 사전 + 자동 문제 생성 | `var TERMS` / `buildTermQuestions()` (~569, 1026줄) | 파트별 용어-정의 쌍을 등록해두면 "다음 중 OOO에 대한 설명으로 옳은 것은?" 형식 문제를 자동 생성. 정답은 항상 그 용어의 정의이고 오답은 다른 용어의 정의라서, 새 용어를 추가해도 정답 오류가 날 수 없는 구조 |
| SQL 실행 결과 문제 | `var EXEC_QUESTIONS` (~1174줄) | 실제 SQLite로 쿼리를 돌려서 결과를 검증한 뒤 만든 문제 |
| 업로드된 문제 은행 | `var UPLOADED_MC` / `UPLOADED_OX` / `MOCK_EXAM` (~1431줄~) | 사용자가 제공한 마크다운 문제집을 파서로 추출해 그대로 반영한 데이터 |
| 이론 콘텐츠 | `var THEORY` (~1295줄) | 이론 탭에 나오는 30개 개념 (정의·표·SQL예제·OX퀴즈) |
| 진도 저장 | `loadProgress()` / `recordAnswer()` 등 (~1764줄) | `localStorage`에 학습 기록 저장 |
| 라우터 | `navigate()` / `render()` (~1851줄) | 해시 없이 `data-nav` 속성 클릭으로 화면 전환 |
| 이론 렌더링 | `renderBlock()` / `renderConceptDetail()` (~1937줄) | 이론 개념 상세 페이지 렌더링 |
| 예상문제 엔진 | `renderQuestion()` 등 (~2230줄) | ANSWER SHEET 사이드바 + 4/5지선다 문제 흐름 |
| OX퀴즈 엔진 | `renderOxQuestion()` 등 (~2419줄) | O/X 문제 흐름 |
| 모의고사 엔진 | `renderMockQuestion()` 등 (~2524줄) | 90분 타이머 + 답안지 레이아웃 + 합격 판정 |

## 콘텐츠 추가하는 방법

### 이론 개념 추가

`var THEORY` 배열에 아래 형태로 항목을 하나 추가하면 이론 탭 목록과 상세 페이지에 자동으로 나타납니다.

```js
{
  id: "새로운-개념-id",
  section: "1-1",           // 1-1, 1-2, 2-1, 2-2, 2-3 중 하나
  cat: "model1",             // section에 대응하는 카테고리
  title: "개념 이름",
  subtitle: "한 줄 설명",
  blocks: [
    { type: "lead", text: "정의 설명" },
    { type: "table", headers: ["컬럼1","컬럼2"], rows: [["a","b"]] },
    { type: "code", text: "SELECT * FROM ..." }
  ],
  ox: [
    { stmt: "참/거짓을 물어볼 문장", answer: true, explain: "해설" }
  ]
}
```

### 예상문제 추가

`var QUESTIONS` 배열에 아래 형태로 추가합니다. 보기는 4~5개 모두 가능합니다.

```js
{
  cat: "sql1",
  q: "문제 내용",
  choices: ["보기1","보기2","보기3","보기4"],
  answer: 0,   // 정답 보기의 인덱스(0부터 시작)
  explain: "해설"
}
```

### 용어 자동 문제로 추가 (더 간단한 방법)

`var TERMS` 안의 해당 파트 배열에 `["용어", "정의"]` 한 줄만 추가하면, 나머지 오답 보기와 문제 형식은 자동으로 만들어집니다.

## 콘텐츠 출처

- 초기 예상문제 30개, 이론 콘텐츠, 용어 사전 기반 문제: 직접 작성
- SQL 실행결과 문제: 실제 SQLite에 데이터를 넣고 쿼리를 돌려 결과를 검증 후 작성
- `UPLOADED_MC` / `UPLOADED_OX` / `MOCK_EXAM`: 사용자가 제공한 마크다운 문제집에서 파서로 그대로 추출 (문제·보기·정답·해설 원문 그대로, 임의로 수정하지 않음)

외부 사이트의 저작권이 있는 기출복원 문제집 내용은 포함되어 있지 않습니다.
