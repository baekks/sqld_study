- 1과목 데이터 모델링의 이해: 10문항

- 연도별 빈출 포인트: 모델링 유의점 · 속성 분류 · 정규화 · NULL · 조인

문자열에서 지정한 위치부터 지정한 길이만큼 부분 문자열을 추출하는 함수. 위치 검색은 INSTR입니다. Oracle 시작 위치는 1부터입니다.

### 46. 1번

행을 유일하게 식별하며 NULL과 중복을 허용하지 않는 제약조건. NULL 허용 중복 금지는 UNIQUE입니다. 테이블당 PK는 하나입니다.

### 47. 1번

정답은 비등가 조인입니다. 급여를 등급 범위에 매핑하는 문제가 대표적입니다.

### 48. 5번

GROUP BY보다 먼저 개별 행을 필터링하는 절. 그룹 조건은 HAVING을 사용합니다.

### 49. 4번

원하는 그룹 조합만 명시적으로 지정하여 집계하는 그룹 확장. 자동 소계는 ROLLUP이고, 모든 조합은 CUBE입니다.

### 50. 3번

COMMIT, ROLLBACK, SAVEPOINT처럼 트랜잭션을 제어하는 언어. 권한 부여·회수는 DCL입니다.
