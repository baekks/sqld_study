# SQLD 2023년 기출 복원 기반 전체 세트

> 공개된 기출 복원 자료의 출제 주제와 경향을 참고해 새로 구성한 학습용 문제입니다. K-DATA 공식 기출 원문이나 특정 회차의 완전한 복제본이 아닙니다.

- 참고 회차: 48~51회
- 시험 구성: 50문항 · 90분
- 1과목 데이터 모델링의 이해: 10문항
- 2과목 SQL 기본 및 활용: 40문항
- 연도별 빈출 포인트: 도메인 · 식별자 최소성 · Top-N · 윈도우 · 서브쿼리
